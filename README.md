Python Expression Parser Calculator

Project Description

A command-line calculator built using Python. It evaluates arithmetic expressions using a custom tokenizer and recursive-descent parser.

Features

- Addition, subtraction, multiplication, and division
- Operator precedence
- Parentheses support
- Multi-digit integer support
- Division-by-zero detection
- Basic invalid-expression handling

Technologies Used

- Python 3

How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run:
   
   "python Expression_Parser_Calculator.py"

5. Enter an arithmetic expression when prompted.
